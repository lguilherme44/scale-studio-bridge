Privacy Policy

Last updated: November 20, 2026.

Scale Studio is a personal tool used only by its owner on their own computer. It is not offered to the public.

Data we access

When the owner connects their TikTok account, Scale Studio receives an access token and basic profile information (display name and avatar) through TikTok Login Kit, and uses the video upload permission to send videos the owner created to the owner's own TikTok drafts.

Where data is stored

Tokens are stored only in a local configuration file on the owner's computer. No data is sent to any server operated by Scale Studio, and nothing is sold, shared or used for advertising.

This website

This page and the authorization bridge page do not use cookies or analytics. The bridge page only forwards the authorization code from TikTok to the Scale Studio app running on the same computer.

Removing access

The owner can revoke access at any time in the TikTok app under Settings and privacy → Security → Manage app permissions, and delete the local configuration file.
